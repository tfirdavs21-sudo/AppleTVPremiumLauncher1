Apple TV Premium Launcher — исходный проект

Требования:
- Android TV / TV Box: Android 7.1.1 (API 25) или новее.
- Проект собирается в облаке через GitHub Actions (JDK 17, Gradle 8.2.1).
- Это исходный проект, НЕ готовый APK.

Сборка с телефона:
1. Войдите на github.com и создайте новый пустой репозиторий.
2. Распакуйте ZIP на телефоне (например, в «Мои файлы»).
3. Загрузите все файлы и папки проекта в репозиторий, сохранив структуру.
4. Откройте вкладку Actions в репозитории.
5. Выберите Build Android APK и нажмите Run workflow (если workflow не запустился автоматически).
6. После завершения откройте запуск workflow и скачайте artifact AppleTVPremium-debug.
7. Распакуйте artifact ZIP — внутри будет app-debug.apk.

На TV Box включите установку приложений из неизвестных источников для файлового менеджера,
перенесите APK на приставку и установите.

Примечание:
Это первая базовая версия: тёмный интерфейс, баннер, часы/дата, список установленных
TV/launcher-приложений и управление пультом. Значки приложений в этой версии отображаются
как универсальный символ; можно улучшить после проверки на вашей приставке.
